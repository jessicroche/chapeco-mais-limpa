# 🌿 Chapecó Mais Limpa

O **Chapecó Mais Limpa** é um projeto web de educação ambiental desenvolvido para facilitar o acesso da comunidade a informações sobre descarte correto de resíduos, Ecopontos, ações educativas e iniciativas relacionadas à sustentabilidade no município de Chapecó.

O projeto foi desenvolvido na disciplina de **Engenharia de Software I**, do curso de **Ciência da Computação da Universidade Federal da Fronteira Sul (UFFS)**.

## 📁 Organização do projeto

O projeto é dividido em duas partes principais:

- **[Frontend](./frontend/README.md)** — interface do sistema, páginas HTML, estilos CSS e JavaScript responsável pela interação com o usuário e comunicação com o Firebase.
- **[Backend](./backend/README.md)** — estrutura de servidor desenvolvida com Node.js e Express, contendo controllers, services, repositories, models e rotas.

Consulte o README de cada pasta para conhecer sua estrutura e funcionamento em detalhes.
