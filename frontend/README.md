# 💻 Frontend — Chapecó Mais Limpa

O frontend é responsável pela interface visual e pela interação do usuário com o sistema.

A aplicação foi desenvolvida utilizando **HTML5, CSS3 e JavaScript**, com integração aos serviços do **Firebase**.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilização, responsividade e temas.
- **JavaScript** — lógica da aplicação, manipulação do DOM e comunicação com o Firebase.
- **Firebase Authentication** — autenticação dos administradores.
- **Cloud Firestore** — armazenamento e consulta dos dados.
- **Firebase Hosting** — hospedagem da aplicação.
